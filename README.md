## 📌 Описание проекта 
Создание интерактивной книги по теме Сказки - "Красная шапочка"

## 🚀 Что реализовано?
Реализована история согласно оригинальной сказки 

## 🛠️Используемые технологии?

Использовались основные блоки - Движение, Внешний вид, События, Условия, а также работа с Костюмами спрайтов и фонами.

Дополнительно было добавлено Музыкальное сопровождение.
